# SATRUGHAN

SATRUGHAN is an offline-friendly UPI QR calculator, billing/POS and Bluetooth 58mm invoice printing web app.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages.

## App branding
- App name: SATRUGHAN
- Launcher icons: assets/icon-192.png and assets/icon-512.png
- PWA manifest: manifest.json
- Service worker: sw.js

## Printing
The Bluetooth/BLE printer workflow and first-print Date/Time initialization fix are retained.
